Before you start

A two-minute read. It will make your feedback far more useful.

What this is

An assistant that answers questions about University of Essex policies and rules of assessment, using about 1,200 official documents. It quotes from those documents and shows you which ones it used.

What it is not

It is not authoritative. It can be wrong, and it can be confidently wrong. Always check the linked source document before acting on anything, and never rely on it for a decision about a specific student without confirming it yourself.

It also has no access to student records, timetables, or anything outside published policy documents.

What to ask it

It is best at questions a policy document actually answers:

What is the pass mark for a PGT Merit?
When is an independent chair required for a PGR viva?
What happens if a student fails more than 15 credits in Year One?

You can ask follow-up questions — it remembers the conversation.

The Essex / Partner switch

Above the message box is a dropdown, set to University of Essex. Some courses are taught at partner colleges (Colchester Institute, East 15, Kaplan, Tavistock and others) which have their own rules-of-assessment documents.

  • University of Essex — answers use Essex documents only. Right for almost everything.
  • Partner colleges — answers use partner documents only. Switch to this if you are asking about a course taught at a partner college.

If you ask about a partner course while set to Essex, it will say it has no document on it. That is the switch working, not a fault — but do tell us if it happens when you did not expect it.

Please use the thumbs

The 👍 / 👎 under each answer is the single most useful thing you can do. It records the question, the answer, and which documents were used, so the failure can be diagnosed properly afterwards.

A thumbs-down with a one-line comment is worth ten without. "Wrong — the pass mark is 50 for this course" tells us far more than a bare thumbs-down.

Things worth reporting

  • An answer that is wrong, especially if it sounds confident.
  • An answer that says it cannot find something you know is in the policies.
  • An answer that cites the wrong document — for example the wrong year, or the wrong programme.
  • Anything that reads like the software talking about itself rather than about policy.
  • Anything slow, broken, or confusing.

Two practical notes

  • Your name. You will be asked for one on first use. It keeps your conversations separate from other testers'. It is not a login and there is no password — please do not treat it as private or put anything sensitive in a question.
  • Speed. Expect a few seconds before text starts appearing, then it writes out gradually. The first question after a quiet period may be slower.
