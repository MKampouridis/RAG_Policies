How to read this

Coverage is scored by description, not code

An answer that describes a milestone without printing its M1.1 label still counts. A label-only count previously scored five complete answers as zero.

Every failure was retried once

Generation varies run to run — one programme scored 15/15 and 1/15 on the same question. A programme counts as incomplete only if it fell short twice.

Health and Social Care is the real outlier

Its PhD returned 6 of 19 milestones on both attempts, with the correct document retrieved. Every other shortfall is one to three milestones.

One wrong document

Philosophy’s Masters by Dissertation returned the History equivalent. Both sit in the same school, and the question names the school, so nothing distinguishes them.

Measured against production

Answers came from the same cloud generator production serves. An earlier version of this run used the local model by default and was discarded.

What is not covered

MSD, Professional Doctorate, DClinPsych and PhP programmes exist in the corpus but were outside this request. Coverage is a word-overlap proxy: fit to audit, not to gate releases.

Generated from eval/questions_milestones.json, itself built from the corpus so it regenerates after an ingest. Milestone documents are 2025–26 editions.
