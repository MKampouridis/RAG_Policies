How to read this

Two ways to present a milestone, both counted

An answer may print M2.7 or describe the milestone in prose. Counted by label: 926/940. By description: 870/940. By either: 940/940 — which is why counting only one signal previously reported failures that were not there.

An earlier version of this report was wrong

It showed 56/63 and 97.4%. Both the scorer and the index have since been fixed; every shortfall it listed was a measurement artefact or a since-repaired retrieval fault.

Programme names now reach the index

Milestone documents carry their programme in the indexed header. Before that, Philosophy’s Masters by Dissertation returned History’s — both sit in one school, and only the school was indexed.

Measured against production

Answers came from the cloud generator production serves, not a local stand-in. Each programme was asked by name, as a student or supervisor would ask.

What 100% does and does not mean

Every milestone the document defines appears in the answer. It does not verify that every description is worded perfectly, only that none is missing.

Includes more than the three main degrees

Beyond PhD, MPhil and Masters by Dissertation, the sweep covers MSD, Professional Doctorate, DClinPsych and PhP programmes — 14 further programmes, all complete.
